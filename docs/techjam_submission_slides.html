01 · Problem framing

This is retrieval under evolving intent—not a one-shot search box

The system must discover a hidden target through conversation, return it in the Top 10, and do so within ten turns.
BrowseVague category; maximize recall.
ClarifyConvert answers into constraints.
CorrectRetract stale preferences safely.
RankOptimize exact target position.

Objective function

S = 0.50·HitRate@10 + 0.30·MRR + 0.20·Efficiency
Efficiency = clip((11 − MTTC) / 10, 0, 1)
  • Recall: did the target appear at all?
  • Rank: how early in the Top 10?
  • Conversation: how many turns did it take?

Why reciprocal-rank fusion?

  • No score calibration between BM25 and cosine similarity.
  • Bounded contribution from any one route.
  • Weights are ablatable and intent-conditioned.
